# Metronic assets

Source: the user-supplied `template-tailwind-html-starter-kit`, package `metronic-tailwind-html` 9.5.0. Its HTML headers identify v9.4.11; the supplied files, rather than an online demo, are the visual reference.

- `src/styles/metronic/config.css`: copied from `src/css/config.ktui.css`.
- `src/styles/metronic/layout-1.css`: copied from `src/css/demos/demo1.css`.
- Container and menu CSS: copied from `src/css/components`.
- `public/metronic/keenicons`: the filled icon CSS and original filled font files only, extracted from the supplied vendor bundle. Other icon families and demo JavaScript are not shipped.
- `@keenthemes/ktui` 1.1.0: CSS components, MIT; installed as an exact dependency. JavaScript initializers are not loaded.
- `public/fonts`: Inter (Latin, Latin Extended and Vietnamese subsets), downloaded from Google Fonts, by Rasmus Andersson, SIL Open Font License 1.1 (`OFL.txt`). All runtime fonts are self-hosted.

Metronic and KeenIcons are by KeenThemes. Retain the original licensing terms supplied with the purchased/downloaded template: https://keenthemes.com/metronic/tailwind/docs/getting-started/license. This integration does not grant or change the template's license.
